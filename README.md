# Fit Race - Interactive 3D Frame Scroll Experience & Cyber Fuel Showcase

A high-performance interactive web application featuring an Apple-style 270-frame canvas scroll animation, paired with the MuscleBlaze Biozyme Cyber Fuel product showcase.

## 🚀 Features

- **270-Frame HiDPI Canvas Engine**: Silky smooth 60fps canvas scroll animation powered by Linear Interpolation (lerp).
- **Preloader & Loader Progress**: Real-time percentage indicator preloading all 270 frames into memory.
- **Centered FIT RACE Display**: Minimalist, aesthetic display typography with cyan/gold ambient glow.
- **Interactive Control Deck**: Timeline scrubber bar, play/pause auto-spin mode, and speed selector.
- **Biozyme Cyber Fuel Showcase**: Complete product specs, flavor selector, live weight price calculator, clinical proof bioavailability charts, and FAQ accordion.
- **Web Audio Ambience**: Built-in Web Audio API chill cafe synth drone generator.

## 🛠️ Built With

- HTML5 / CSS3 / JavaScript (ES6+)
- Vite (Dev Server & Bundler)
- Tailwind CSS
- Web Audio API

## ⚡ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/snogdox/fit-race.git
   cd fit-race
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start dev server:
   ```bash
   npm run dev
   ```
